# 🔢 Assignment 7 — Find the Largest of Three Numbers

A lightweight console utility built with Python that takes three numbers from the user, determines the maximum value among them using Python's built-in `max()` function, and outputs the result.

---

## 🎮 How It Works

1. Prompts the user three times to input numbers via the console using `input()`.
2. Converts each string input into an integer and stores them in `num1`, `num2`, and `num3`.
3. Passes all three variables as arguments into Python's built-in `max()` function to identify the largest value.
4. Displays the maximum value along with a descriptive message using `print()`.

---

## 🛠️ Concepts Practised

- Reading console input using `input()`
- Type conversion from string to integer using `int()`
- Utilizing the built-in `max()` function to compare multiple arguments
- Storing input data across multiple distinct variables
- Displaying labels alongside computed output with `print()`
