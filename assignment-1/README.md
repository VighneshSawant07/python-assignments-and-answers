# 🐍 Assignment 1 — Hello World

A classic first step into programming built with Python. This script outputs the timeless greeting to standard output, verifying the development environment and foundational language syntax.

---

## 📝 Assignment Question:-

**Print hello world.**

---

## 🎮 How It Works

1. The script initializes the Python runtime environment.
2. Calls the built-in `print()` function.
3. Passes the string argument `"HELLO WORLD!"`.
4. Transmits the text directly to the console/standard output stream.
5. Terminates execution cleanly with an exit code of `0`.

---

## 🛠️ Concepts Practised

- Executing a `.py` script via the command line.
- Using standard output with the built-in `print()` function.
- Defining string literals using double quotes (`"..."`).
- Understanding standard Python script entry points and execution flow.
