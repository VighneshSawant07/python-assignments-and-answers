# ➕ Assignment 2 — Sum of Two Numbers

A simple interactive console program built with Python that takes two numeric inputs from the user, computes their addition, and displays the calculated sum.

---

## 📝 Assignment Question
**Program to add two integers. Take input from user.**

---

## 🎮 How It Works

1. The script prompts the user to enter the first number via the console.
2. Converts the entered input string into an integer and assigns it to variable `x`.
3. Prompts the user to enter a second number.
4. Converts the second input into an integer and assigns it to variable `y`.
5. Calculates the sum using the addition operator (`+`) and stores the result in `sum`.
6. Prints a formatted message to standard output showing the final sum.

---

## 🛠️ Concepts Practised

- Taking dynamic user input using `input()`.
- Type casting/conversion from string to integer using `int()`.
- Variable declaration and assignment.
- Basic arithmetic operations (addition with `+`).
- Output formatting with `print()` passing multiple comma-separated arguments.
