# 🔢 Assignment 3 — Square of a Number

A lightweight console utility built with Python that takes a number from the user, calculates its square using multiplication and outputs the result.

---

## 🎮 How It Works

1. Prompts the user with `"Enter a number to find its square"` via the console.
2. Reads the input and casts it into an integer stored in variable `x`.
3. Calculates the square by multiplying the value by itself (`x * x`) and stores the result in variable `sq`.
4. Displays the final squared value to the screen using `print()`.

---

## 🛠️ Concepts Practised

- Reading console input with `input()`
- Type conversion from string to integer using `int()`
- Arithmetic multiplication using the `*` operator
- Storing intermediate calculation results in variables
- Printing combined string messages and variable values
