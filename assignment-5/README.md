# 🏏 Assignment 5 — Area of a Cricket Stadium

A lightweight console script built with Python that calculates the total area of a circular cricket stadium having a 30-meter radius using Python's built-in `math` module.

---

## 📝 Assignment Question

**A cricket stadium has radius 30 meter. What is the area of stadium.**

---

## 🎮 How It Works

1. Imports Python's built-in `math` module to access high-precision mathematical constants.
2. Uses the standard circle area formula (`Area = π × r²`) with a fixed radius of 30 meters.
3. Multiplies `math.pi` by `30 * 30` and stores the resulting value in variable `area`.
4. Outputs the descriptive message along with the calculated area using `print()`.

---

## 🛠️ Concepts Practised

- Importing built-in standard library modules using `import`
- Utilizing mathematical constants (`math.pi`) for high precision
- Applying geometric formulas via basic arithmetic multiplication (`*`)
- Variable assignment and floating-point numeric storage
- Formatting and displaying descriptive text alongside numeric output with `print()`
